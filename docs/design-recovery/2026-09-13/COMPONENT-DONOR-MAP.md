## Explicit no-copy boundaries

- **Agent Cockpit:** information architecture evidence only. No source, CSS, DOM, or assets are copied.
- **LinkCode:** semantic and interaction evidence only under BUSL. No implementation is copied.
- **Reasonix, dsh-synapse, OpenCode:** MIT donors. Their component anatomy and mechanics may be transplanted, with attribution retained when production reconnection is eventually authorized.
- The static lab deliberately mirrors ownership and state contracts. It does not add a second production component library or reconnect any runtime path.
